# Mishkal Wall

The Mishkal mastering limiter (replaces Goliath's Chomah as its own plug-in).

Chain: PUNCH > CHARACTER > BANDS > LEVELER > GOLD > CLIPPER (drag into any order) > LIMITER > CEILING.
Oversampled (Off / 2x / 4x / 8x), true-peak ceiling that nothing passes, LUFS metering, streaming preview.

Build on the Mac with `Build Wall.command` (Xcode + CMake, JUCE 8.0.4). Check with `Check Wall.command` (auval aufx Wall Mshk).
